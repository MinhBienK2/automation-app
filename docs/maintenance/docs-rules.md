# Docs Rules

## Audience

Write for coding agents only.

## Style

- English only.
- Short sections.
- Bullets and tables over prose.
- File paths and commands over explanations.
- Invariants and checklists over history.

## Avoid

- Roadmap language.
- Phase history.
- Spec decisions from `docs/superpowers`.
- Long code copies.
- User-facing marketing or product copy.
- Unverified statements about current code.

## Prefer

- Source file paths.
- Ownership boundaries.
- Hidden coupling.
- Required checks.
- Explicit docs update triggers.

## Soft Size Budgets

- `docs/README.md`: 120 lines or fewer.
- `docs/task-routes.md`: concise route table/details.
- Domain, architecture, contract, and maintenance files: usually 80-150 lines.
